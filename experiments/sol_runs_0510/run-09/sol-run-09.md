# 구로구 버스 파업 대체 셔틀 운행안

## 노선별 운행

- **R01** 개봉1동 굴다리·호반써밋 → 오류동역 / 1대 / 개봉1동사거리 일대의 수요를 모아 오류문화센터 정류장에서 철도로 연결한다.
- **R02** 고척1동 유풍약국 → 구일역 / 1대 / 고척중학교와 고척시장 인근을 짧게 연결하고 동양미래대학·구로성심병원 정류장에서 하차시킨다.
- **R03** 항동 푸른수목원 → 온수역 / 1대 / 역곡역이 가장 가까운 항동 수요를 모아 유한공고·성공회대앞 정류장에서 온수역으로 연결한다.
- **R04** 수궁119안전센터 → 온수역 / 1대 / 수궁동과 예림디자인고 일대를 우신중고후문 정류장까지 연결해 항동 방면 차량과 승차권역을 나눈다.
- **R05** 천왕이펜하우스 5단지 → 천왕역 / 1대 / 5·6단지 쪽 수요를 모아 3단지입구 정류장에서 철도로 연결한다.
- **R06** 개봉3동 대원카센터 → 광명사거리역 / 1대 / 개봉 남부와 한진아파트 일대 수요를 모아 개명초교 정류장에서 철도로 연결한다.
- **R07** 신도림중학교 → 구로역 / 1대 / 신도림동 주거지의 수요를 구로역 북측 정류장으로 짧게 연결한다.
- **R08** 구로변전소·구로초등학교 → 구로역 / 1대 / 구로2동 수요를 구로역 남측 정류장으로 연결해 신도림동 노선과 승차권역을 나눈다.
- **R09** 구로도서관·대성스카이렉스 → 대림역 / 1대 / 거리공원·구로구청 인근 수요를 구로고등학교 정류장까지 연결한다.
- **R10** 고대구로병원 정문 → 남구로역 / 1대 / 병원과 구로119안전센터 주변 수요를 구로시장 정류장으로 모아 짧게 회차한다.
- **R11** JNK디지털타워·구로남초등학교 → 구로디지털단지역 / 1대 / 두 승차점으로 구로3동과 가리봉동 일부를 묶고 KEB하나은행 정류장에서 철도로 연결한다.

## 서비스가 부족한 수요와 권역

- 철도망에 포함된 수요 중 약 5,109명은 출발 정류장에서 각 노선의 승차 지점까지 직선 500m를 넘는다. 이 중 개봉역 권역 1,562명, 오류동역 권역 1,018명, 구일역 권역 698명, 양천구청역 권역 511명의 접근 공백이 크다. 개봉역 인근과 고척 북부, 오류동 서쪽, 구로1동을 모두 경유하면 회차가 길어지므로 수요가 모인 지점을 우선했다.
- 양천구청역과 역곡역은 `access.csv`에 하차 연계점이 없다. 고척 일부는 구일역으로, 항동 일부는 온수역으로 연결한다. 가산디지털단지역 ID `1702`를 기준으로 묶이는 권역과 신정네거리역 권역도 승차 접근 공백이 크다.
- 승차 지점이 500m 이내인 수요도 만차나 20분 대기 상한으로 일부 수송이 어렵다. `rail_known=0`인 829명은 전체 16,230명에 포함하며 도착 인원으로 계산하지 않는다.

## 비교에 사용한 가정

시간대별 출발은 해당 시간 안에서 균등하게 분산된다고 가정했다. 승차 전 보행은 분당 74~80m, 셔틀은 직선거리 기준 시속 13.8~18.6km, 정류장 정차는 21초, 마지막 정류장에서 첫 정류장으로 복귀한 뒤 회차 여유는 3.4~5분으로 두었다. 하차 후 보행에는 `access.csv`의 시간을 사용했다. 철도 이동은 역간 직선거리에 1.3을 곱해 시속 34.2km로 환산하고 대기·환승 여유 12분을 더해 근사했다.

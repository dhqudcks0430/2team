# 구로구 파업 대체 셔틀 운행안

## 노선별 배분

- R01 항동 푸른수목원 → 온수역 / 1대 / 유한공고·성공회대 앞에서 내려 온수역으로 걸어가도록 해 역곡역이 가장 가까운 항동 수요를 연결한다.
- R02 수궁동주민센터 일대 → 온수역 / 1대 / 궁동·수궁동 주거지 수요를 모아 럭비구장 정류장에서 도보 환승한다.
- R03 개봉동 대상아파트·연지마을 → 천왕역 / 1대 / 광명사거리 권역 일부와 천왕권 수요를 함께 태워 이펜하우스3단지 입구에서 환승한다.
- R04 거성푸르뫼아파트 일대 → 오류동역 / 1대 / 오류동 북쪽 주거지의 집중 수요를 오류1동주민센터 정류장까지 짧게 수송한다.
- R05 용두연립 일대 → 개봉역 / 1대 / 개봉 서쪽과 오류동 동쪽의 수요를 개봉사거리로 보내 오류동행과 나눈다.
- R06 고척 북부 경남아파트·성화단지 → 개봉역 / 1대 / 두 승차 지점에서 고척 북부와 양천구청역 권역의 수요를 모아 개봉사거리에서 환승한다.
- R07 현대아파트·개봉중앙시장 → 개봉역 / 1대 / 개봉 남부에서 현대2차아파트까지 짧게 연결해 시장 주변 수요의 역까지 도보 구간을 줄인다.
- R08 고척동 유풍약국 일대 → 구일역 / 1대 / 고척시장 남쪽 수요를 동양미래대학·구로성심병원 정류장으로 모아 구일역에 연결한다.
- R09 신도림중학교 일대 → 구로역 / 1대 / 신도림·도림천 권역 일부를 구로역 정류장까지 짧게 연결해 승차 기회를 늘린다.
- R10 고대구로병원 후문 일대 → 대림역 / 1대 / 병원 주변과 구로4동 수요를 구로중학교 정류장으로 모아 대림역에 연결한다.
- R11 구로남초등학교·디지털탑프라자 → 구로디지털단지역 / 1대 / 가리봉동과 디지털단지의 두 승차권을 묶어 구 사조참치 정류장에서 환승한다.

## 남는 수요와 판단 근거

- 구로역 권역의 한국SGI·구로보건소 일대, 구일역 권역의 구로1동, 역곡역 권역의 항동 서쪽 일부는 이 안의 승차 지점에서 직선 500m를 벗어난다. 신정네거리역 권역의 29명도 별도 노선 없이 남는다. 이 지역까지 노선을 연장하면 왕복이 길어져 45석 차량의 반복 운행 횟수가 줄어든다.
- 07시대 수요는 8,855명으로 08시대 7,375명보다 많다. 특히 고척 북부와 오류동 북쪽에서는 정류장까지 걸어올 수 있어도 만차로 다음 차를 기다릴 수 있다. 긴 노선에 차를 집중하기보다 가까운 철도역으로 가는 노선을 여러 권역에 배치해 회차를 짧게 했다. 철도망 미확인 829명은 전체 16,230명의 분모에 포함했다.

## 설계 가정

- 좌표로 승차 정류장까지의 직선 500m 도보권과 가장 가까운 역 권역을 구분했고, 하차 후 도보 시간은 `access.csv`를 사용했다.
- 후보 비교에서는 도로 주행거리를 직선거리의 1.3배, 주행속도를 시속 23km, 정류장 정차를 약 17초씩, 한 회차의 회차 여유를 약 1분 30초로 두었다. 마지막 정류장에서 출발점으로 돌아와 같은 순서로 반복 운행하는 것으로 보았다. 철도 구간의 이동·환승 시간과 도로 정체 자료는 제공되지 않아 실제 소요시간에는 불확실성이 있다.

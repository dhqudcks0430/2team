# 구로구 파업 대체 셔틀 운행안

- **R01** 개봉중학교·개봉1동사거리 → 오류동역 / 1대 / 개봉1동 북부의 밀집 수요를 모아 오류문화센터에서 철도로 잇는다.
- **R02** 고척시장·고척중학교 → 구일역 / 1대 / 시장과 학교 주변을 한 번에 태우고 동양미래대학·구로성심병원에서 철도로 잇는다.
- **R03** 대원주유소·개봉한진아파트 → 광명사거리역 / 1대 / 개봉3동 남부의 수요를 모아 개명초교에서 7호선으로 잇는다.
- **R04** 항동복합행정센터·푸른수목원 → 온수역 / 1대 / 항동하버라인과 수목원 주변을 태워 역곡역 인근으로 분류되는 항동 수요에도 대체 철도 연결을 제공한다.
- **R05** 예림디자인고·수궁119안전센터 → 온수역 / 1대 / 수궁동 학교와 주거지의 수요를 짧은 노선으로 1·7호선에 연결한다.
- **R06** 천왕이펜하우스 5·6단지 및 3·4단지 → 천왕역 / 1대 / 단지 남쪽의 출근 수요를 모아 2번 출구 가까이에서 하차시킨다.
- **R07** 신도림중학교 일대 → 구로역 / 1대 / 이름이 같은 두 실제 정류장에서 신도림 북서부 수요를 태우고 신도림동·구로역 정류장에서 철도로 잇는다.
- **R08** 구로보건소·한국SGI → 신도림역 / 1대 / 구로동 북동부와 거리공원 일대에서 1·2호선을 이용할 수 있게 한다.
- **R09** 우리유앤미아파트·구로변전소 → 구로역 / 1대 / 구로초등학교 주변을 짧게 운행해 구로역 1번 출구에 연결한다.
- **R10** 구로119안전센터·고대구로병원 정문 → 남구로역 / 1대 / 병원 앞과 구로4동 주거지 수요를 구로시장 하차 지점에서 7호선으로 잇는다.
- **R11** 삼부르네상스·가리봉파출소·디지털단지오거리 → 남구로역 / 1대 / 가리봉과 디지털단지 남쪽의 수요를 남구로역 2번 출구로 모은다.

## 수송이 어려운 수요와 권역

전체 16,230명 중 4,308명은 각 노선의 마지막 하차 지점을 제외한 승차 정류장에서 직선 500m 밖에 있다. 가까운 철도역으로 나눈 권역별로는 개봉 1,225명(2,297명 중), 구일 742명(1,460명 중), 양천구청 319명(651명 중), 구로디지털단지 207명(329명 중)이 여기에 해당한다.

개봉역·한마을아파트와 개봉역 주변은 CSV상 철도 도보 연결이 있어, 개봉 남부 노선은 철도 접근이 어려운 개봉한진아파트 일대를 우선했다. 구일 남쪽 구로1동과 고척 북쪽 고척파크푸르지오·고척고교까지 우회하면 회차가 길어져 기존 승차 지점의 대기와 만차 부담이 커진다. 구로디지털단지역 일대는 역 주변보다 남쪽 주거지와 가리봉을 우선했다. 항동은 역곡역과 500m 이내 도보 연결이 등록된 하차 정류장이 없어 온수역에 연결한다.

철도망 미확인 수요 829명은 전체 수요에 포함되며 도착으로 인정되지 않는다. 07시대 철도망 확인 수요는 8,808명으로 08시대의 6,593명보다 많아, 밀집 구간에서 45석이 차면 20분 안에 다음 차량을 타기 어려울 수 있다.

## 검토 가정

승차 전 보행은 시속 4.4km, 셔틀은 시속 19~23km로 두었다. 도로 주행거리는 직선거리의 1.24~1.30배, 정차는 지점당 약 25~29초, 종점에서 첫 정류장까지의 복귀 주행 외 회차 여유는 2.5~3분으로 가정했다. 하차 후 보행은 access.csv 값을 사용했고, 철도 시간은 역 사이 직선거리 1km당 2.8분과 승차·환승 여유 4~13분으로 근사했다. 이 가정으로 90분 내 도착 가능성과 10분 내 탑승 가능성을 함께 고려해 노선과 차량 배분을 고른다.

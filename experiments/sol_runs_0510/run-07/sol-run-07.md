# 구로구 버스 파업 대체 셔틀 운행안

- R01 항동복합행정센터 → 온수역 / 1대 / 항동과 역곡 권역의 출근 수요를 모아 럭비구장에서 온수역 두 노선으로 연결한다.
- R02 우신중고등학교후문·수궁동주민센터 → 온수역 / 1대 / 궁동과 수궁동의 수요 밀집 지점 두 곳을 지나 온수역에서 하차한다.
- R03 천왕이펜하우스5단지 → 천왕역 / 1대 / 이펜하우스 단지군의 수요를 모아 연지타운2단지에서 하차하며, 짧은 회차로 대기를 줄인다.
- R04 개봉소공원·호반써밋개봉아파트 → 오류동역 / 1대 / 개봉1동사거리와 인근 아파트의 집중 수요를 오류1동주민센터·오류문화센터까지 짧게 연결한다.
- R05 경남아파트앞·개봉1동주민센터 → 개봉역 / 1대 / 고척·개봉 북부의 여러 출발 정류장을 두 승차 지점으로 모아 개봉사거리에서 하차한다.
- R06 고척시장 → 구일역 / 1대 / 고척시장과 덕의초교 일대에서 승객을 모아 동양미래대학·구로성심병원 정류장에서 구일역으로 연결한다.
- R07 대원주유소·개봉한진아파트 → 광명사거리역 / 1대 / 개봉 남부 두 수요 밀집지를 지나 광명사거리역까지 도보 연결이 있는 개명초교에서 하차한다.
- R08 구로1동주민센터·구로119안전센터 → 구일역 / 1대 / 구로1동과 안전센터 일대의 수요를 묶어 현대상선·구일중학교 정류장에서 구일역으로 연결한다.
- R09 구로구민회관·구로고대병원후문 → 대림역 / 1대 / 구청·병원 일대의 출근 수요를 모아 대림역 4번 출구에서 두 철도 노선으로 연결한다.
- R10 롯데아파트·구로보건소·구로변전소 일대 → 구로역 / 1대 / 구로보건소와 구로초 일대에서 승객을 태운 뒤 구로역까지 도보 연결이 있는 롯데아파트로 돌아온다.
- R11 삼부르네상스·효성아파트·디지털단지오거리 → 가산디지털단지역·남구로역 / 1대 / 남부 산업단지 주변 수요를 모아 가리봉시장에서 목적지에 따라 두 역으로 걸어갈 수 있게 한다.

## 서비스가 제한되는 수요와 권역

- 목적지가 철도망에 포함된 수요 중 승차 정류장까지 직선 500m를 넘고 출발 정류장의 직접 철도 연결도 없는 수요는 999명이다. 가장 큰 공백은 오류동 권역 311명, 천왕 권역 132명, 구일 권역 106명이다. 동부골든아파트·오류중학교, 천왕의 금강수목원아파트 일대, 구일의 제일제당 일대를 더 경유하면 회차가 길어져 밀집 승차 지점의 배차 여력이 줄어든다.
- 도림천 권역 183명 중 철도망 목적지가 있는 134명은 출발 정류장에 도림천역 도보 연결이 있다. 차량을 다른 권역에 배분해 동아1차아파트105동 33명은 승차 범위 밖에 남는다. 역곡 권역은 항동에서 온수역으로 연결하지만, 편도 거리가 상대적으로 길어 1대의 좌석과 배차 간격이 제약이 된다.
- 07시대에 8,855명이 출발하므로 여러 출발지를 아우르는 노선에서는 만차로 대기가 길어질 수 있다. 목적지가 철도망에 포함되지 않은 829명은 전체 16,230명에 포함된다.

## 비교에 사용한 가정

출발은 각 시간대 안에서 고르게 분포한다고 가정했다. 도로 거리는 정류장 간 직선거리의 1.4배, 셔틀 주행속도는 시속 16~22km, 승차 정류장 정차는 30초, 회차 여유는 2분으로 두었다. 철도 이동 부담은 역 간 직선거리의 1.35배를 시속 29km로 이동하는 시간에 대기·환승 여유 13분을 더해 근사했다. 하차 뒤 도보는 `access.csv`의 시간을 사용했다.

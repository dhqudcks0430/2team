# 구로구 버스 파업 대체 셔틀 운행안

- R01 항동중학교·푸른수목원 일대 → 온수역 / 1대 / 역곡역이 가장 가까운 항동 일부 수요를 유한공고·성공회대앞에서 온수역 두 역 ID로 연결한다.
- R02 서울가든빌라·궁동 남부 → 천왕역 / 1대 / 우신중고·궁동청소년문화의집 주변에서 승차하고 금강수목원아파트에서 천왕역까지 걷는다.
- R03 오류1동주민센터·개봉1동사거리 일대 → 오류동역 / 1대 / 출근 수요가 모이는 구간에서 승차해 역 2번 출구와 가까운 정류장에서 내린다.
- R04 개웅어린이공원·개봉3동 → 개봉역 / 1대 / 개봉한진아파트와 개봉중앙시장 일대 수요를 모아 개봉역 남쪽에서 환승시킨다.
- R05 고척시장·서울가든아파트 → 개봉역 / 1대 / 고척시장 방향 수요를 공구상가 정류장까지 짧게 운송한다.
- R06 동양미래대학·한마을아파트 → 개봉역 / 1대 / 123전자타운·2001아울렛 주변 수요를 모아 고척시장 방향 노선과 승차 지점을 나눈다.
- R07 신도림중학교·신도림동 → 신도림역 / 1대 / 동아2차아파트상가에서 신도림역 두 역 ID에 걸어서 접근할 수 있다.
- R08 롯데아파트·한국SGI 일대 → 구로역 / 1대 / 신도림동·구로역 정류장 주변과 한국SGI 일대의 수요를 모아 구로역 정류장에서 내린다.
- R09 구로구청·구로초등학교 일대 → 대림역 / 1대 / 구청 후문 일대에서 승차해 구로고등학교 정류장에서 대림역으로 걷는다.
- R10 고대구로병원 정문·구로시장 입구 → 남구로역 / 1대 / 병원 정문과 구로4동 주거지 수요를 모아 남구로역에 도보로 연결되는 구로시장 정류장에서 내린다.
- R11 가리봉·디지털단지오거리 동쪽 → 남구로역 / 1대 / 웰크론과 구로남초등학교 두 곳에서 수요를 모아 구로3파출소를 통해 남구로역으로 연결한다.

## 서비스가 제한되는 수요

출발 정류장에서 각 노선의 종점 앞 승차 지점까지 직선 500m를 적용하면, 합산 수요 16,230명 중 6,681명이 승차권 밖에 있다. 오류동 권역은 북쪽 개봉1동의 일부 정류장까지 거리가 길어 1,399명, 구일 권역은 구로1동 남부와 승차 지점 사이가 멀어 800명이 이 범위를 벗어난다. 천왕 남부 이펜하우스 일대와 양천구청 방향 고척 북단에도 각각 권역 수요 1,008명 중 789명, 651명 중 529명이 남는다. 역곡·양천구청 권역의 해당 철도역은 `access.csv`에 연결 정류장이 없어 항동 일부는 온수역, 고척 북단 일부는 개봉역으로 보낸다. 철도망 밖 목적지 수요 829명은 전체 분모에 포함되며 도착 인원으로 인정되지 않는다.

## 노선 비교에 사용한 가정

승차 전 보행은 분당 75m, 셔틀은 직선거리의 1.30배를 시속 16km로 주행한다고 가정했다. 정류장당 39초, 종점 회차 여유 3분, 최소 한 바퀴 7.5분을 적용했다. 하차 후 도보 시간은 `access.csv`를 쓰고, 철도 시간은 역 간 직선거리의 1.35배를 시속 26km로 이동하는 시간에 대기·환승 10분을 더해 후보 비교에 사용했다. 07시대와 08시대 수요를 따로 합산해 45석 공급을 비교했다. 수요가 몰릴 때 만차로 다음 차량을 기다릴 수 있고, 회차가 긴 항동은 10분 이내에 탑승하기 더 어렵다.

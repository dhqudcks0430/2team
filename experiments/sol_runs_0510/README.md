# 범용 AI 셔틀 설계 실험 run-05 ~ run-10 (gpt-6.2-sol)

구로구 버스 파업 대체 셔틀을 범용 AI가 설계하게 한 실험의 제출물입니다. 같은 과제를 6회 반복했습니다.

## 조건

- 모델: Codex `gpt-6.2-sol`, reasoning effort `high`. run마다 새 세션 하나를 썼습니다(Orca 워커, 2026-11-18).
- 과제: 각 `run-XX/PROMPT.md`. 회차 사이 차이는 제출 ID(`sol-run-XX`)뿐입니다.
- 차량: 11대(45인승). 수요: 16,230명(`rail_known=0` 829명 포함).
- 입력: `inputs/`의 CSV 4개(`stops`, `stations`, `demand`, `access`). 6회 모두 같은 파일입니다(md5 일치).
- 각 세션에는 자기 run 폴더만 쓰고, 다른 회차·저장소·평가기·웹에는 접근하지 말라고 지시했습니다.

- 6회 모두 짧은 노선 11개에 1대씩 배분했습니다.
- 회차 사이에 같은 노선은 run-07과 run-10의 1개뿐입니다.
- 각 제출물의 노선별 근거와 미서비스 권역 설명은 `run-XX/sol-run-XX.md`에 있습니다.

## 형식 검사

```bash
python experiments/sol_runs_0510/check_submissions.py
```

정류장 ID가 `inputs/stops.csv`에 있는지, 연속 중복, 노선당 정류장 2개 이상, `route_id` 중복, 차량 양의 정수, 합계 11대를 확인합니다.

## 아직 하지 않은 것

- 시뮬레이터 채점(90분 내 도착, 10분 내 탑승·90분 내 도착, 평균 대기, 도착률 10% 미만 권역 수요)은 하지 않았습니다.
- 이 입력(16,230명, 철도 이동 포함 90분 기준)에 맞는 평가기를 로컬에서 찾지 못했습니다.
- 저장소의 구로 v4 번들은 수요가 15,824명이라 그대로 쓸 수 없습니다.
